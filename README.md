The Invisible Ink Printer — a catalogue photograph of an impossible gadget.

A sleek studio product shot of a small printer caught mid-use: it prints in
invisible ink, so its output is a perfectly blank page. One accessory sharpens
the joke — a cartridge of invisible ink standing beside it, its droplet
hollow, its label honest.

## The joke, at a glance

- The product is labelled **INVISIBLE INK** — model PRT-0, tagline
  "PRINTS NOTHING - PERFECTLY".
- The page coming out of the output slot is completely blank.
- The single accessory is an **INVISIBLE INK** cartridge: dark, upright,
  with a hollow teal droplet on its label — the ink you cannot see.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024 PNG, well under 1 MiB). Pure Python
standard library, no network, fully deterministic — the program draws the
whole photograph itself, pixel by pixel (own tiny rasterizer + PNG encoder,
plus a 5×7 bitmap font for the product lettering).
